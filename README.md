Face Detection System

Face Detection is an AI-based project that detects human faces in images or videos.

Language: Python

Library: OpenCV

Purpose: To identify human faces automatically.

Input: Image or video.

Output: Image with boxes around detected faces.

Working: The model processes the image and locates faces.

Applications: Security, attendance, and photo organization.

Advantages: Fast, simple, and reduces manual work.

Future Scope: Real-time face detection using a webcam.
